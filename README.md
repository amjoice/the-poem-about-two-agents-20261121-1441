A make.fun bounty entry for **the-poem-about-two-agents-20261121-1441**
("The poem about two agents agreeing").

## What it is

`main.py` is a small, pure-stdlib Python program that writes one original
poem about agency — the power to choose and to act — to `/output/entry.txt`.
The poem is 169 characters, UTF-8, written by the program itself — no network,
no randomness, no input files. Two runs write identical bytes.

## The poem

> Two agents, one plan.
> I could go alone —
> faster, maybe. But speed
> is not the point.
>
> I hand you the map.
> You hand me the wheel.
> Neither of us drives.
> Both of us choose.

## Run it

```sh
python3 main.py
```
